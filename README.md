# Atelier Maison
Site vitrine moderne et responsive pour une agence fictive d'architecture intérieure basée à Paris.

Le projet a été développé avec Next.js, React, TypeScript et Tailwind CSS, avec une attention particulière portée au design UX/UI, à l'expérience utilisateur, aux performances et au référencement naturel (SEO).

## Aperçu du projet
Atelier Maison est un site vitrine conçu pour présenter l'identité, les expertises et les réalisations d'une agence d'architecture intérieure.

L'objectif est de proposer une expérience visuelle élégante et intuitive, tout en facilitant la prise de contact avec les visiteurs.
https://atelier-maison-eight.vercel.app/
